# Keyword-to-Page Map

**Project:** Softabyte Labs  
**Phase:** 0 — Planning only  
**Date:** August 19, 2026  
**Market:** United States  
**Status:** **FROZEN**

No search volumes, KD, CPC, or traffic estimates are included. See `keyword_strategy.md`.

**Rule:** one primary keyword → one primary page.

Suggested titles and metas are drafts for later implementation. They must stay accurate. Do not add fake awards or “#1” claims.

**Homepage copy rule:** The homepage primarily targets brand/navigation, broad software/product/technology partner relevance, and commercial positioning for US businesses. Do **not** force unnatural exact-match keywords into copy. High-intent service keywords belong on dedicated service pages.

Character guidance: titles ~50–60 characters where possible; metas ~140–160. Some drafts may run slightly long and should be trimmed at implementation with the live brand domain.

## Cannibalization watchlist

| Risk pair | Resolution |
|---|---|
| Custom Software vs Web | Custom = systems of record / internal platforms; Web = sites and web products |
| Web vs Ecommerce industry | Web primary stays “web development company”; Ecommerce stays operator/vertical |
| AI vs Custom Software | AI = intelligence/automation layer; Custom = the system being built or extended |
| Hosting vs Web | Hosting = run/care; Web = build |
| Process vs Custom Software process blog | Process = our delivery; blog = educational |

If two drafts share an H1 intent, combine them before design/build.
